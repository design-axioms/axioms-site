# Axiomatic home (`axioms.design`)

The shared front door for **Axiomatic** at <https://axioms.design/>, introducing
the relationship-first design model and linking to Axiomatic Layout
(<https://layout.axioms.design>) and Axiomatic Color
(<https://color.axioms.design>).

Read [the website architecture plan](docs/WEBSITE-PLAN.md) for the roadmap
across `axioms.design`, Color, Layout, and the sequenced `ts-docs` follow-up.

## Local preview & validation

Use the Node version in `.node-version` and the pnpm version in
`package.json`:

```sh
pnpm install --frozen-lockfile
pnpm serve     # http://127.0.0.1:8789/, rebuilt as you edit
pnpm verify    # types, formatting, tests, build, and checks on the build
```

The page is `public/index.html`. Its behavior and styles are `src/site.ts`
and `src/site.css`. `pnpm build` writes the published site to `dist/`:

- `public/` copied as it is;
- `assets/color.css`, generated by Axiomatic Color. The card uses a static surface,
  and interactive controls retain their hover and active colors;
- `assets/site.js` and `assets/site.css`, bundled from `src/` together with
  the Axiomatic Layout package and its stylesheet.

The exact package archives this
site uses are kept under [`vendor/`](vendor/README.md), each with a record of
its upstream commit and file hashes, so a clean checkout builds on its own.

The preview applies the redirect rules in `vercel.json` before it looks for
a file, as Vercel does. A legacy Color path answers with its redirect
locally, and an asset that a rule would capture is missing locally too.

## Publish the static site

Merging a pull request into `main` publishes the shared homepage. The Vercel
project `yehuda-katzs-projects/axioms-site` is connected to this repository
with `main` as its production branch. Vercel installs the frozen lockfile,
runs `pnpm build`, and assigns `axioms.design` to the successful build.

Vercel reports production deployments to GitHub. On a successful production
status, the [Site checks workflow](.github/workflows/site-checks.yml) exercises
the investigation on the public domain in Chromium, Firefox and WebKit and
checks the legacy Color redirects. A failed check appears in GitHub Actions.
You can rerun the workflow manually or check the live release locally:

```sh
AXIOMS_SITE_URL=https://axioms.design pnpm test:browser
```

### Domain & link-preservation commitments

- Keep `axiomatic-layout.vercel.app` serving the Layout playground without a
  custom-domain redirect: its browser-local drafts belong to that origin.
- Preserve `www.axioms.design` (or a dedicated `v1.color.axioms.design` archive)
  for legacy Color v1 links until a deliberate retirement/redirect pass is
  prepared.
- `vercel.json` forwards the earlier Color site's paths from the apex to
  `www.axioms.design`, where its links and sitemap still point: the
  `/concepts`, `/guides`, `/theory`, `/catalog`, `/advanced`, `/reference`,
  `/studio`, `/hud`, `/why-axiomatic`, `/philosophy` and
  `/alpha-limitations` families, plus `/llms.txt`, `/llms-full.txt`,
  `/sitemap-index.xml` and `/sitemap-0.xml`. Every other path belongs to
  this site. Vercel applies redirects before it looks for a file, so a new
  page must stay outside those families. `scripts/routes.ts` holds the list
  and the checks enforce it (see
  [docs/WEBSITE-PLAN.md](docs/WEBSITE-PLAN.md)).
- The original Color domain assignment was `axioms.design` redirecting to
  `www.axioms.design` on Vercel project `color-site`. Record any changed domain
  assignment and rollback plan before altering apex or subdomain bindings.
